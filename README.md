# Teste Automatizado de Busca - Loja Relva Verde 🌱

Este projeto apresenta um teste automatizado de busca para o site [Loja Relva Verde](https://www.lojarelvaverde.com.br/), utilizando Selenium e Node.js. O teste verifica a funcionalidade de busca no site, incluindo localização do ícone de busca, envio de termos de pesquisa e validação dos resultados exibidos.

## 📋 Funcionalidades Testadas

1. Carregamento da página inicial.
2. Localização e interação com o ícone de busca.
3. Envio de texto para a barra de pesquisa.
4. Validação dos resultados exibidos e contagem de itens retornados.
5. Captura e exibição dos preços dos primeiros itens.

## 🛠️ Tecnologias Utilizadas

- [Node.js](https://nodejs.org/)
- [Selenium WebDriver](https://www.selenium.dev/)
- [Mocha](https://mochajs.org/) *(opcional, para execução de testes)*
- Google Chrome (com ChromeDriver)
